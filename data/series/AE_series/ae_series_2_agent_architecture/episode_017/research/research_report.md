# 调研报告

本次调研发现，代码 Agent 正处于从“玩具”向“生产力工具”跨越的关键阶段。以 SWE-agent 为代表的系统通过优化 Agent-Computer Interface (ACI)，证明了大模型在真实软件工程（如解决 GitHub Issue）中的巨大潜力。当前的架构趋势正从复杂的多 Agent 交互转向更精准的 AST 级别定位及轻量级/无 Agent 架构。与此同时，以 E2B 和 OpenAI Code Interpreter 为核心的安全沙箱技术解决了 LLM 执行代码的信任危机。尽管面临 Token 成本和超长上下文检索的挑战，代码 Agent 在 2025 年必将成为开发者日常工作的标配辅助工具。

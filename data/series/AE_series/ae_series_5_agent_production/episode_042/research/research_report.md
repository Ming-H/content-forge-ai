# 调研报告

本次调研聚焦于专用 Agent 领域的两大核心方向：软件工程（SWE-agent）与数据分析（Data Agent）。研究显示，专用 Agent 正在褪去“过度包装的框架”，回归“强大基座模型+极简领域工具”的本质（如 100 行代码的 mini-swe-agent 凭借优秀的 ACI 设计即可达到 65% 解决率）。在 Data Agent 方面，Text-to-SQL 与自动可视化的成熟架构已经能够替代大量初级数据清洗与报表工作。未来垂类 Agent 的核心壁垒不在于代码复杂度，而在于如何将业务领域的 Schema、业务指标字典和逻辑沉淀到 RAG 和工具的 docstring 中，从而实现精准的领域知识注入。
